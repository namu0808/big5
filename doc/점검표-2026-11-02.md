# 다이얼 완료 점검표 (PLAN 12장) — 2026-11-02, 버전 0.9.0

> **2026-11-04 배포 위치 변경**: www.sbm.ai.kr/big5/ (sonbm.com/big5/ 에서 대표님 테스트 완료 후 이전, 새로 설치). 설치 순서는 `doc/배포-안내.md`.

- 검증 환경
  - SQLite 개발 DB, 그리고 **운영과 같은 MariaDB 10.11**에서 모두 확인했다. MariaDB는 `sql_mode`를 운영보다 엄격하게(ONLY_FULL_GROUP_BY 포함) 두었다.
  - 배포 묶음(zip)을 풀어 개발 파일 없이 띄운 상태에서도 확인했다.
- 일괄 실행
  - `node doc/pw/run.js` (SQLite)
  - `BIG5_TEST_DB=mysql node doc/pw/run.js` (MariaDB)

## 이번 단계에서 더한 것
- MariaDB 검증 도구
  - `doc/dev-db-mysql.php`
  - `BIG5_TEST_DB=mysql`: 브라우저 스모크와 DB를 쓰는 CLI 테스트가 MariaDB로 돈다
- 반응형 스모크 `doc/pw/responsive-smoke.js`
- 보안 헤더
  - `.htaccess`: nosniff, SAMEORIGIN, Referrer-Policy same-origin
  - `<meta name="referrer" content="same-origin">`: 타인 평가 링크의 토큰이 외부 요청 Referer로 새지 않게
- 배포 묶음 `doc/make-dist.php` → `dist/big5-deploy-YYYYMMDD.zip`, 목록 `doc/배포-파일목록.txt`(64개), 안내 `doc/배포-안내.md`
- 코드 훑기 결과
  - 출력 이스케이프: 이스케이프 없이 찍는 값은 숫자 집계·고정 문구뿐
  - SQL: 모든 SQL은 자리 표시자를 쓴다(users.php의 WHERE는 자리 표시자만 담은 고정 문장)
  - CSRF: POST를 받는 화면 11개 모두 CSRF 검사
  - innerHTML: 사용하지 않음

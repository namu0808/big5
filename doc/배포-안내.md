# 다이얼 배포 안내 (sonbm.com/big5/)

- 대상 버전: 0.9.0 (배포 후보)
- 배포 묶음: `dist/big5-deploy-YYYYMMDD.zip` (`php doc/make-dist.php` 로 만든다)
- 파일 목록: `doc/배포-파일목록.txt` (64개)
- 서버: 카페24 웹호스팅, PHP 8.x, MariaDB 10.x
- 설치 위치: `{홈}/www/big5/`
- 아래 순서대로 한 번만 하면 됩니다. 각 단계 끝의 **확인**을 꼭 보세요.

---

## 1. DB 준비

1. 카페24 DB(MariaDB)에 접속해 문자 집합을 확인합니다. 호스팅 DB를 그대로 써도 됩니다.
   - `utf8mb4` / `utf8mb4_unicode_ci`
   - 다이얼 테이블은 모두 `big5_` 로 시작해서 WordPress 테이블과 섞이지 않습니다.
2. DB 이름·아이디·비밀번호를 적어 둡니다.

## 2. 설정 파일 만들기 (웹루트 밖)

1. 묶음의 `config/big5_db.sample.php`를 서버의 **`{홈}/config/big5_db.php`** 로 올립니다.
   - `{홈}/www` 가 아니라 그 **바깥**입니다. FTP 처음 화면에서 `www` 폴더와 나란히 `config` 폴더를 만듭니다.
2. 파일을 열어 값을 채웁니다.
   - `BIG5_DB_HOST`: 보통 `localhost`
   - `BIG5_DB_NAME`, `BIG5_DB_USER`, `BIG5_DB_PASS`
   - `BIG5_EXPORT_SALT`: **40자 이상의 무작위 문자열**. 관리자 CSV의 익명 해시에 쓰입니다. 한 번 정하면 바꾸지 마세요(바꾸면 예전 CSV와 이어지지 않습니다).
   - `BIG5_BASE_URL`: `'/big5'` 그대로
3. **확인**: 이 파일은 웹 주소로 열 수 없어야 합니다(www 바깥이므로 자동으로 그렇습니다).

## 3. 프로그램 올리기 (FTP)

1. 묶음의 `big5/` 폴더 **안의 내용**을 서버 `{홈}/www/big5/` 에 올립니다.
2. 점으로 시작하는 파일 3개가 빠지지 않게 하세요. FTP 프로그램에서 '숨김 파일 보기'를 켭니다.
   - `big5/.htaccess`
   - `big5/includes/.htaccess`
   - `big5/data/.htaccess`
3. 올리지 않는 것: 저장소의 `doc/` `tests/` `1time/` `data/source/` `data/translate/` `PLAN.md` `CLAUDE.md` 원고 파일
   - 묶음에는 이미 빠져 있습니다.

## 4. 설치 (한 번만)

1. 묶음의 `install.php` 를 `{홈}/www/big5/install.php` 로 올립니다.
2. 브라우저로 **https://sonbm.com/big5/install.php** 를 엽니다.
   - '설치 완료'와 함께 테이블 9개, 초기 계정 2개(sonbm 관리자 / user 사용자, 비밀번호 visang)가 만들어집니다.
3. **바로 `install.php` 를 서버에서 삭제합니다.**
4. **확인**: https://sonbm.com/big5/install.php → '찾을 수 없음'(404)

## 5. 초기 비밀번호 바꾸기

1. https://sonbm.com/big5/login.php 에서 `sonbm` / `visang` 으로 로그인
   - [계정] → 비밀번호 바꾸기
2. `user` 계정은 시험용입니다. 같은 방법으로 비밀번호를 바꾸거나, [계정] → '내 데이터 전체 삭제'로 지웁니다.
3. 관리자 화면: https://sonbm.com/big5/admin/login.php (sonbm)

## 6. 운영 확인

| 주소 | 기대 결과 |
|---|---|
| https://sonbm.com/big5/ | 다이얼 시작 화면 (WordPress 화면이 아님) |
| https://sonbm.com/big5/includes/db_config.php | 403 Forbidden |
| https://sonbm.com/big5/data/items_120.json | 403 Forbidden |
| https://sonbm.com/big5/data/content/fixed.json | 403 Forbidden |
| https://sonbm.com/big5/admin/index.php (로그인 전) | 관리자 로그인 화면으로 이동 |
| https://sonbm.com/ (WordPress) | 예전처럼 정상 |

문제가 생기면 다음을 확인하세요.
- **500 오류**
  - 호스팅이 `.htaccess`의 일부 설정을 막는 경우입니다.
  - `big5/.htaccess`의 `Options -Indexes` 줄을 지우고 다시 열어 보세요.
  - 그래도 안 되면 카페24 '에러 로그'를 확인합니다.
- **'잠시 이용할 수 없습니다'**
  - DB 연결 실패입니다.
  - `{홈}/config/big5_db.php` 경로와 값을 확인합니다. 파일 이름은 `big5_db.php`, 폴더는 www 바깥 `config` 입니다.
- **/big5/ 가 WordPress 404로 뜬다**: `big5/.htaccess`가 올라갔는지 확인합니다. 이 파일이 WordPress의 주소 재작성 규칙을 끊습니다.

## 7. 문구 확인

- 신경성 높은 쪽 결과에 나오는 '정신건강 상담 전화 1577-0199(24시간)'의 번호와 운영 시간을 최신 정보로 다시 확인합니다(PLAN 8장).
- 바꿀 곳: `data/content/domains.json`의 `N.high.help_line`, `data/content/fixed.json`의 `help.line`

## 8. 본인 검사와 검수

1. 대표님 계정으로 정식 검사를 한 번 끝까지 합니다.
2. 리포트를 읽고, 인쇄/PDF도 저장해 봅니다.
3. 고칠 문구는 `data/review_content.md`(해석 문구)·`data/review_items.md`(문항 번역)에 적어 주세요. 반영한 뒤 status를 final로 바꾸고 1.0.0으로 올립니다.

## 다시 배포할 때 (업데이트)

- 바뀐 파일만 올려도 됩니다. 커밋 기록에서 바뀐 파일을 확인하거나, `php doc/make-dist.php` 로 새 묶음을 만들어 덮어씁니다.
- `install.php` 는 테이블이 바뀔 때만 다시 올려 실행하고 삭제합니다. 여러 번 실행해도 기존 데이터는 지워지지 않습니다.
- `{홈}/config/big5_db.php` 는 덮어쓰지 마세요.

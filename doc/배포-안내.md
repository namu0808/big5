- 올릴 파일 4개(`{홈}/www/big5/` 아래 같은 자리), install 없음: `index.php`, `includes/header.php`, `includes/version.php`, `assets/style.css`
- 바뀌는 것
  1. 상단이 공부력 진단과 같은 모양입니다 — 왼쪽 SBM 표식(누르면 **사이트 홈**) + 'Dial / 빅파이브(Big5) 성격 검사'(누르면 다이얼 시작), 메뉴 'SBM 진단 검사 홈'·내 기록·타인 평가·다이얼 기록, 오른쪽 '○○님 [내 계정]' 또는 [로그인]

- 홈 0.5.2·공부력 진단 0.5.1 과 함께 올립니다(각 저장소 `doc/배포-안내.md` 맨 위 절)

> 0.9.x 에서 올리는 순서(홈·코어 → 다이얼 → `migrate_sbm_users.php` 로 계정 이전)는 **sbm.ai.kr 저장소 `doc/배포-안내.md`** 를 따르세요.
> 아래는 0.9.1 때의 다이얼 단독 설치 기록입니다(새 서버에 처음 설치할 때 참고 — 그때도 코어를 먼저 올립니다).

- 대상 버전: 0.9.1 (배포 후보)
- 서비스 위치: **https://www.sbm.ai.kr/big5/** (2026-11-04, sonbm.com/big5/ 에서 옮김). 새 서버에 **새로 설치**합니다. 테스트 데이터는 옮기지 않습니다. 기존 sonbm.com/big5/ 정리는 대표님이 직접 처리합니다.

- 설치 위치: `{홈}/www/big5/`
- 아래 순서대로 한 번만 하면 됩니다. 각 단계 끝의 **확인**을 꼭 보세요.

## 1. DB 준비

1. 카페24 DB(MariaDB)에 접속해 문자 집합을 확인합니다. 호스팅 DB를 그대로 써도 됩니다.
   - `utf8mb4` / `utf8mb4_unicode_ci`
   - 다이얼 테이블은 모두 `big5_` 로 시작해서 같은 DB의 다른 테이블과 섞이지 않습니다.
2. DB 이름·아이디·비밀번호를 적어 둡니다.

## 2. 설정 파일 만들기 (웹루트 밖)

1. 묶음의 `config/big5_db.sample.php`를 서버의 **`{홈}/config/big5_db.php`** 로 올립니다.
   - `{홈}/www` 가 아니라 그 **바깥**입니다. FTP 처음 화면에서 `www` 폴더와 나란히 `config` 폴더를 만듭니다.
2. 파일을 열어 값을 채웁니다.
   - **새 서버(sbm.ai.kr)의 DB 접속 정보**를 씁니다. sonbm.com 의 설정 파일을 그대로 복사하지 마세요.
   - `BIG5_DB_HOST`: 보통 `localhost`
   - `BIG5_DB_NAME`, `BIG5_DB_USER`, `BIG5_DB_PASS`
   - `BIG5_EXPORT_SALT`: **40자 이상의 무작위 문자열을 새로 만듭니다** (새로 설치하므로 sonbm.com 때 값과 같을 필요가 없습니다). 관리자 CSV의 익명 해시에 쓰입니다. 한 번 정하면 바꾸지 마세요(바꾸면 예전 CSV와 이어지지 않습니다).
   - `BIG5_BASE_URL`: `'/big5'` 그대로 (도메인은 넣지 않습니다)
3. **확인**: 이 파일은 웹 주소로 열 수 없어야 합니다(www 바깥이므로 자동으로 그렇습니다).

## 3. 프로그램 올리기 (FTP)

1. 묶음의 `big5/` 폴더 **안의 내용**을 서버 `{홈}/www/big5/` 에 올립니다.
2. 점으로 시작하는 파일 3개가 빠지지 않게 하세요. FTP 프로그램에서 '숨김 파일 보기'를 켭니다.
   - `big5/.htaccess`
   - `big5/includes/.htaccess`
   - `big5/data/.htaccess`
3. 올리지 않는 것: 저장소의 `doc/` `tests/` `1time/` `data/source/` `data/translate/` `CLAUDE.md` (계획서·원고는 `doc/` 안에 있습니다)
   - 묶음에는 이미 빠져 있습니다.

## 4. 설치 (한 번만)

1. 묶음의 `install.php` 를 `{홈}/www/big5/install.php` 로 올립니다.
2. 브라우저로 **https://www.sbm.ai.kr/big5/install.php** 를 엽니다.
   - '설치 완료'와 함께 테이블 9개, 초기 계정 2개(sonbm 관리자 / user 사용자, 비밀번호 visang)가 만들어집니다.
3. **바로 `install.php` 를 서버에서 삭제합니다.**
4. **확인**: https://www.sbm.ai.kr/big5/install.php → '찾을 수 없음'(404)

## 5. 초기 비밀번호 바꾸기

1. https://www.sbm.ai.kr/big5/login.php 에서 `sonbm` / `visang` 으로 로그인
   - [계정] → 비밀번호 바꾸기
2. `user` 계정은 시험용입니다. 같은 방법으로 비밀번호를 바꾸거나, [계정] → '내 데이터 전체 삭제'로 지웁니다.
3. 관리자 화면: https://www.sbm.ai.kr/big5/admin/login.php (sonbm)

## 6. 운영 확인

| 주소 | 기대 결과 |
|---|---|
| https://www.sbm.ai.kr/big5/ | 다이얼 시작 화면 (루트 사이트 화면이 아님) |
| https://www.sbm.ai.kr/big5/includes/db_config.php | 403 Forbidden |
| https://www.sbm.ai.kr/big5/data/items_120.json | 403 Forbidden |
| https://www.sbm.ai.kr/big5/data/content/fixed.json | 403 Forbidden |
| https://www.sbm.ai.kr/big5/admin/index.php (로그인 전) | 관리자 로그인 화면으로 이동 |
| https://www.sbm.ai.kr/ (루트 사이트) | 예전처럼 정상 |
| https://sbm.ai.kr/big5/ (www 없는 주소) | 다이얼이 열리거나 www 주소로 넘어감. 호스팅의 대표 도메인 설정에 따라 다르며, 둘 다 열려도 괜찮습니다 |

문제가 생기면 다음을 확인하세요.
- **500 오류**
  - 호스팅이 `.htaccess`의 일부 설정을 막는 경우입니다.
  - `big5/.htaccess`의 `Options -Indexes` 줄을 지우고 다시 열어 보세요.
  - 그래도 안 되면 카페24 '에러 로그'를 확인합니다.
- **'잠시 이용할 수 없습니다'**
  - DB 연결 실패입니다.
  - `{홈}/config/big5_db.php` 경로와 값을 확인합니다. 파일 이름은 `big5_db.php`, 폴더는 www 바깥 `config` 입니다.
- **/big5/ 가 루트 사이트의 404로 뜬다**: `big5/.htaccess`가 올라갔는지 확인합니다. 이 파일이 루트 사이트(WordPress 등)의 주소 재작성 규칙을 끊습니다. 루트가 WordPress가 아니어도 그대로 둡니다.
- **타인 평가 링크 주소**: 초대 링크는 접속한 주소 그대로 만들어집니다. www 주소로 접속해 만들면 `https://www.sbm.ai.kr/big5/rate.php?t=…` 가 됩니다.

- `install.php` 는 테이블이 바뀔 때만 다시 올려 실행하고 삭제합니다. 여러 번 실행해도 기존 데이터는 지워지지 않습니다.
- `{홈}/config/big5_db.php` 는 덮어쓰지 마세요.
